# Nerdy Popcorn for macOS

Official Nerdy Popcorn Mac downloads are published in this repository’s Releases.
For download, installation and account information, visit the [Mac download page](https://nerdypopcorn.ca/macos.html).

The first Mac package is for Apple silicon. Download the DMG, open it, drag Nerdy Popcorn to Applications, and open the app from Applications. Updates preserve your saved account, playlists, settings and recordings.

Each release includes checksums and the corresponding VideoLAN library source collection. Third-party license and attribution notices are also included inside the application bundle.
